https://drive.google.com/drive/folders/1PXzHyferlhxyKfkiv1oDLTIRhbGUPWA4?usp=sharing

Expected local path after download or sync:
`paper_arxiv/references/pdfs/`

2. Download or sync the PDF collection.
3. Place the files into `paper_arxiv/references/pdfs/`.
4. Keep that directory out of git tracking.
